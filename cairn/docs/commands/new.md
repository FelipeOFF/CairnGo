# /cairn:new

> Start a new cairn project — GSD new-project, then create the bd issues and
> generate the phase↔beads maps

## Usage

```text
/cairn:new
```

No arguments. Kicks off a new project end to end, under the cairn conventions.

## What it does

**Guard first:** if `.planning/` already exists, the command refuses and stops
— the repo already has GSD history. It routes to
[/cairn:migrate](./migrate.md) instead; `/gsd:new-project` is never run over
an existing `.planning/`.

1. If `bd` or `.beads/` is missing, run [/cairn:init](./init.md) first and
   stop.
2. Run `/gsd:new-project` — the interactive interview that creates
   `.planning/` and the ROADMAP.
3. Once the roadmap exists, apply the cairn skill: for every requirement,
   `bd create` one issue with the label pair `m-<milestone>,phase-<N>` and the
   metadata stamp
   `--metadata '{"gsd": {"req": "CAT-NN", "phase": N, "milestone": "vX.Y"}}'`.
   The pair (`gsd.req`, `gsd.milestone`) is the dedup key — a re-run updates
   the existing issue, it never duplicates. Roadmap-implied ordering is
   captured with `bd dep add`.
4. Generate each phase's map — never hand-write the tables:
   ```bash
   bash "${CLAUDE_PLUGIN_ROOT}/scripts/cairn-map.sh" <N>   # once per phase
   ```
5. Confirm: `bd list` shows the new issues and each phase directory has its
   generated `NN-BEADS-MAP.md`.

Then the loop is [/cairn:plan N](./plan.md) → [/cairn:work N](./work.md) →
[/cairn:ship](./ship.md).

### Side effects

- Issues are created in `.beads/` via `bd create`, stamped and labeled.
- Each `bd create` run through Bash also triggers the plugin's PostToolUse
  hook (fire-and-forget mirror push when sync is configured, plus a phase-map
  refresh) — a side effect of any bd write, not specific to this command.
- `NN-BEADS-MAP.md` files are generated into the phase directories.
- No commits are made by the command itself.

## Flags & arguments

None. The interview inside `/gsd:new-project` collects everything.

## Examples

```text
/cairn:new           # fresh repo, bd installed
→ /gsd:new-project interview … ROADMAP created with 3 phases, 9 requirements
→ bd create ×9 (stamped, labeled m-v1.0,phase-1…3) · bd dep add ×4
→ maps: 01-BEADS-MAP.md, 02-BEADS-MAP.md, 03-BEADS-MAP.md
→ next: /cairn:plan 1
```

```text
/cairn:new           # repo already has .planning/
→ refused: this repo has GSD history. Run /cairn:migrate instead.
```

## Files touched

- **Reads:** `.planning/ROADMAP.md`, `.planning/REQUIREMENTS.md` (written by
  the GSD interview).
- **Writes:** `.beads/` (via `bd create` / `bd dep add`),
  `.planning/phases/*/NN-BEADS-MAP.md` (generated by `cairn-map.sh`).
