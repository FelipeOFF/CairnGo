# cairn init

On Codex, first read the [Codex adapter](../../references/codex.md) for paths
and tool mapping. Then follow [cairn-init](../../commands/cairn-init.md).
The selected command is `init`; text after the skill invocation supplies
its arguments, not another command. The arguments are an optional target directory; default to the current repository.
