# cairn sync-pull

On Codex, first read the [Codex adapter](../../references/codex.md) for paths
and tool mapping. Then follow [cairn-sync-pull](../../commands/cairn-sync-pull.md).
The selected command is `sync-pull`; text after the skill invocation supplies
its arguments, not another command. The arguments are optional pull flags. Require an enabled backend and report conflicts.
