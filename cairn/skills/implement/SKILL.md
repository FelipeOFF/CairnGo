# cairn implement

On Codex, first read the [Codex adapter](../../references/codex.md) for paths
and tool mapping. Then follow [cairn-implement](../../commands/cairn-implement.md).
The selected command is `implement`; text after the skill invocation supplies
its arguments, not another command. The arguments are an optional spec, ticket or milestone reference.
