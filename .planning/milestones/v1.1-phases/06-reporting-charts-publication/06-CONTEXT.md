<decisions>
## Implementation Decisions (locked)

### Charts (REPT-02) — SVG hand-rolled stdlib, NOT gnuplot
- Deliberate deviation from STACK.md's gnuplot lean (which the research itself rated a judgment call): gnuplot is an external system dependency; this repo's identity is stdlib-only + deterministic, and the needed charts are simple grouped bar charts (cost/tokens per baseline, per task). `bench-chart.py` emits deterministic SVG (fixed viewBox, sorted elements, no timestamps inside the SVG body — the DATE + model id go in a visible caption text element sourced from a --label argument, and in the filename).
- Charts are generated FROM aggregated.json only. Bats proves determinism (same input → byte-identical SVG) and correctness (values in the SVG match the aggregate) using synthetic aggregates. **Zero SVG committed until real collection data exists.**
- Chart design (honest, minimal): grouped bars per task × baseline for cost-per-successful-run; pass_rate shown alongside (a cost bar without its pass rate is the lie the research warned about); 4-way token decomposition as stacked segments. No decorative styling — monochrome + one accent per baseline, text labels with real values.

### BENCHMARKS.md (REPT-01) — methodology-first, published NOW
- Sections: Methodology (harness, isolation, fairness, gating, corpus, cost model — link the existing README anchors), Raw data (links `benchmarks/results/*.jsonl` — the 2 real Phase 1 rows exist and are linked as the first data points, labeled as schema-validation runs, NOT comparison results), Results (explicit "pending first full collection — reproduce with the command below"), Reproduction (REPT-04 command + cost ceiling), Changelog (dated; corpus changes land here per Phase 5's pre-declaration rule).
- Root README links BENCHMARKS.md.

### README embed (REPT-03)
- `bench-publish.py` injects the results summary between `<!-- cairn:generated:benchmarks:start/end -->` markers in BENCHMARKS.md's Results section (and optionally a one-line teaser in the root README) — exact cairn-map marker pattern, manual content outside markers survives, file without markers gets append (never destroyed).
- Until real data: the machinery is proven in bats against synthetic aggregates in temp copies; the committed BENCHMARKS.md carries the markers with the pending notice inside.

### One-command reproduction (REPT-04)
- `benchmarks/scripts/bench-all.sh`: stage-plugins → bench-matrix (full corpus × 4 arms × 5 reps) → bench-aggregate → bench-report/chart/publish. Flags: `--dry-run` (prints the plan + cost ceiling, $0 — default when ANTHROPIC_API_KEY absent, with loud notice), `--yes` to actually spend. Proven end-to-end in bats with the stub ($0).
- Documented in BENCHMARKS.md Reproduction section with the cost ceiling from the Phase 5 cost model.

### Test strategy
- Everything stub/synthetic, CI $0, determinism double-run diffs. Conditional-live discipline unchanged.
