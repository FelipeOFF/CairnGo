<objective>
Extend the seeded-interleaving orchestrator (Phase 2's `bench-matrix.py`/`bench-run.py`) to cover repetitions: `bench-matrix.py` gains `--reps` (default 5) and shuffles the FULL `baseline x rep` cross-product with one `random.Random(seed)` instance, so no baseline's repetitions are ever launched as a contiguous block; `bench-run.py` gains an optional `--rep-index` mirroring the existing `--seed`/`--run-order-index` flags exactly, stamped into the row only when provided.

Purpose: METR-01 requires N>=5 repetitions per (task, baseline) cell with interleaving extended to cover reps, not just baselines (cache fairness) — this is a harness-design-time decision that cannot be retrofitted onto an already-run suite (ROADMAP.md Phase 3 rationale). This plan produces the REPEATED raw rows; `03-02-PLAN.md` turns them into the median/spread/success-gated statistics artifact.
Output: `bench-run.py` with `--rep-index`; `bench-matrix.py` with `--reps` (default 5) and a cross-product `build_execution_order`; `tests/bench-matrix.bats` extended with interleaving/rep_index coverage, all pre-existing invocations preserved via explicit `--reps 1`.
</objective>
