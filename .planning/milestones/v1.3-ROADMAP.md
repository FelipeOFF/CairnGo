# Roadmap: CairnGo

## Milestone: v1.3 (shipped 2026-07-28) ✅

**Status Panel — a surface you can act on**

The status surfaces stopped rendering a phase as a number. One shared phase model feeds the terminal board, --json and the HTML page; the board describes pending phases, computes the next /cairn:* commands in dependency order with the reason for that order, and says what can run at the same time.
