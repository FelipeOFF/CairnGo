# Plano 37-01: A troca — o plugin fica autocontido

## Objetivo

O `cairn` deixa de depender de um plugin externo para existir. A entrada `gsd-core` sai do
marketplace e das dependências, os 13 wrappers formais param de delegar para fora, e o
`preflight` que os guardava passa a olhar para dentro do próprio plugin — continuando a
poder falhar, que é a única coisa que o torna uma guarda.

## Contexto

@.planning/phases/37-troca-de-plugin/37-CONTEXT.md — D-01, D-02, D-05.

Medido antes de planejar: dos 13 `wraps:`, apenas `discuss-phase` tem contrapartida em
`cairn/gsd/commands/gsd/` (8 arquivos). Os outros 12 delegam para comandos que o plugin não
carrega e que não podem ser vendorizados offline.
