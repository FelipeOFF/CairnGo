# Phase 9 Plan 01 — record a decision for every gsd-core command

## Why

gsd-core ships 71 commands. Wrapping them wholesale would double cairn's surface
for no gain; ignoring them leaves "why isn't there a `/cairn:` version of this?"
to be re-argued every time someone asks. The requirement asks for neither — it
asks for a decision per command, written down.

## Tasks

1. **Derive the real list.** Enumerate gsd-core's commands from the installed
   copy, subtract what cairn references, and record the delta. Do not reuse the
   research note's figure without checking it.

2. **State the rule** before applying it: a wrapper is earned when the command
   changes work beads must know about.

3. **Write the table** — three sections, one row per command, each with what the
   command does and why it landed where it did.

4. **Track the deferred work.** File the thirteen wrap decisions as one bd issue
   with `discovered-from` provenance rather than leaving them as prose.

5. **Link it** from the docs index and the READMEs.

## Verification

- Every one of the 54 unreferenced commands appears in exactly one table.
- The re-derivation command in the doc reproduces the same list.
