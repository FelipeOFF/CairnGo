# Phase 7 Plan 01 — point cairn at the official GSD and prove the capability lands

## Why

The plugin is built around a fusion that has never run for anyone. `/cairn:init`
ends its capability step in `|| echo "capability install skipped"`, so every
failure returned 0; and the lineage it was installed against has no `capability`
subcommand to begin with. Pointing at `open-gsd/gsd-core` is not source hygiene —
it is what makes the central feature exist. Verifying the install is what keeps it
from silently disappearing again.

## Tasks

1. **Manifests.** Rename the marketplace's `gsd` entry to `gsd-core`, source it from
   `open-gsd/gsd-core` with `ref: v1.8.0`, and update the description to say why it
   is pinned. Switch `cairn/.claude-plugin/plugin.json`'s dependency to `gsd-core`.

2. **`cairn-capability.py` + `.sh`.** New script pair in the house style
   (python3 stdlib-only, thin bash wrapper, `die(msg, code)`):
   - `detect` — read-only report of lineage, registration and staging.
   - `install` — install (with `capability update` as the re-run fallback), then run
     the same verification and let *that* decide the exit code.
   - Discovery: PATH first, then the plugin cache, newest version first; a `.cjs`
     entry point is invoked through `node` so the 4.x line is findable and therefore
     *reportable*.
   - Exit codes: 0 ok, 2 usage, 5 no GSD, 7 failure. Every failure carries a remedy.

3. **`/cairn:init` step 2.** Call the script; branch on its exit code; state plainly
   that `/gsd:*` will not touch bd issues when it is 7. Never swallow non-zero.

4. **Reference sweep.** Update the live docs and `cairn-init.sh`'s plugin check,
   which additionally distinguishes "GSD 4.x installed" from "GSD absent". Leave the
   CHANGELOG and `benchmarks/baselines/gsd-only.json` alone — one is history, the
   other is a pin that reproducibility depends on.

5. **CI.** Add a workflow-level `GSD_CORE_REF`, shallow-clone the tag, export
   `GSD_CORE_DIR` and `CAIRN_REQUIRE_GSD_VALIDATOR=1`. Make `capability.bats` turn a
   skip into a failure when that variable is set.

6. **Tests.** `tests/cairn-capability.bats` covering usage, lineage, the three
   look-fine-but-are-not paths (not listed / disabled / staged without the gate
   script), read-only `detect`, and both JSON shapes.

## Verification

- `bats tests/` green with `CAIRN_REQUIRE_GSD_VALIDATOR=1` and a pinned checkout.
- `cairn-capability.sh detect` on this machine reports the legacy lineage and exits
  7 — the honest answer, and the one the old code never gave.
- An install into a scratch project against real gsd-core exits 0 and `capability
  list` reports cairn active.
