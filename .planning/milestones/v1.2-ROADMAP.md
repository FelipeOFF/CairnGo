# Roadmap: CairnGo

## Milestone: v1.2 (shipped 2026-07-28) ✅

**GSD Core — official source, working fusion**

cairn stopped depending on a GSD lineage that could not host it. The marketplace moved to the official open-gsd/gsd-core pinned to a release tag, the capability install began verifying that it registered instead of assuming, doctor started reporting which lineage is installed, and every gsd-core command cairn does not wrap got a written decision.
