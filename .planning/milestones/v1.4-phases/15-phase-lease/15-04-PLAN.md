<objective>
Wire the heartbeat's two session-lifecycle ends: `session-start.sh` renews
the heartbeat of any lease this worktree already holds, and `session-stop.sh`
releases every lease this worktree holds, mirroring the exact place and
format the existing in_progress-issue-claim warning already established
(D-03, and the codebase's own "same place, same format" note).

Purpose: D-03's mechanism only works if the hooks actually run. This plan's
second task is not decoration — it is the one place this whole phase's
riskiest, explicitly-named assumption gets a real test: prove that when
renewal never happens, the resulting staleness is a visible fact, not a
silent one.

Output: two small, guarded additions to already-existing hook scripts, each
following the "never fail the caller" contract those files already
document, plus the test that proves the staleness-visibility guarantee
this phase's design depends on.
</objective>
