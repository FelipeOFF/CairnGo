<objective>
Extend `post-bd-write.sh`'s existing `bd close` handling with a best-effort
attempt to populate `--external-ref gh-<PR#>` on the closing issue — the
going-forward half of CORR-08 (Plan 13-03's `--link-refs` is the backfill
half for history that already happened). Because this hook's contract is
"fire-and-forget, never fail the caller," a write failure here would
otherwise vanish exactly like the bug shape this milestone exists to remove
— so this plan's second deliverable is making that failure provably land
somewhere a human or `/cairn:doctor` can find it.

Purpose: D-12 names this exact risk explicitly and requires a test proving
the failure surfaces, not just a design that assumes it will. This plan
deliberately does NOT touch beads' own `prepare-commit-msg` `Bd-Issue:`
trailer (D-13): this repo squash-merges every PR, which discards that
trailer at merge time exactly as it has discarded every bd id from 239
commits so far — the trailer stays useful for local inspection and
non-squashed history, but `--external-ref` matched to the squash commit's
`(#N)` is the only linkage that actually survives the merge, which is why
it is this plan's whole focus.
Output: a best-effort external-ref write on `bd close`, and a persistent,
append-only log capturing its failures instead of `/dev/null`.
</objective>
