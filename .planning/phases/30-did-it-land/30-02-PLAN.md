# Fase 30 Plano 02 — a PR não descobrível é `desconhecido` com motivo, nunca "sem PR"

## O caso que decide se a fase foi honesta

A PR **#21** deste repositório trouxe o milestone v1.4 inteiro. Ela existe, foi
mergeada, e o commit que ela virou é

```
7fa133c  v1.4 Honest State: phase state that proves what it claims (ships cairn 1.5.0)
parents=[bd03384 8f0c90a]
```

Medido hoje: é um merge commit de verdade (dois pais), e **nem o assunto nem o
corpo nomeiam a PR**. Um board que reportasse "sem PR" para o maior merge do
projeto estaria mentindo.

Medido no histórico inteiro: **14** commits carregam `(#N)` no assunto, **6**
merge commits dizem `Merge pull request #N`, e a #21 não deixa rastro nenhum.

## O que este plano entrega

`cairn-land.py report` passa a carregar, por fase, um bloco `pr`:

```json
"pr": {"status": "found", "number": 18, "numbers": [18],
       "source": "squash-subject", "commit": "f73adc6", "reason": null}
"pr": {"status": "unknown", "number": null, "numbers": [],
       "source": null, "commit": null, "reason": "no-reference"}
```

O vocabulário tem **duas** palavras, `found` e `unknown`, e não existe uma
terceira que diga "não há PR" — porque essa afirmação não é derivável do
histórico local. `reason` é `no-commits` (nada atribuído à fase) ou
`no-reference` (há commits, nenhum nomeia PR), e `detail` diz em palavras que a
única fonte consultada é o histórico local e que um assunto reescrito no merge
não deixa rastro.

O board mostra `#N` como parte do sufixo `⤒` quando a PR existe, e nada quando
é `unknown` — a mesma disciplina do dado condicional. Quem **cobra** uma
ausência é o doutor (plano 30-04), não o card.

## Verificação

- Fixture portátil que reproduz a forma da #21: um merge commit cujo assunto é
  próprio, sem número, trazendo o trabalho de uma fase → `unknown` /
  `no-reference`, e o texto **não** contém "no PR".
- Teste contra o histórico **real** deste repositório, com pré-condição
  verificada (pula se `7fa133c` não existir): a #21 produz `unknown`, nunca
  "sem PR".
- As duas formas descobríveis (`Merge pull request #N`, `… (#N)`) produzem
  `found` com a `source` exata.
- Quebra deliberada: fazer `unknown` virar "no pull request" derruba a
  asserção que proíbe a frase.
