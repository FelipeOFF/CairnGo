<objective>
Wire the lease built in Plan 15-01 into the two points where phase work
actually starts and stops. Acquisition happens twice, deliberately, for two
different reasons: once in `work.md` before the per-plan claim loop (LEASE-
01's "see this before you enter"), and again in `execute-wave-pre.md` before
every wave (the ongoing heartbeat for a phase whose execution outlives a
single session-start renewal). Release happens once, in `verify-post.md`,
unconditionally — pass or fail, that is where a phase's cycle ends.

Purpose: a mechanism nobody calls is not a feature. This plan is the
difference between "cairn-lease.py exists" and "two agents on the same
phase is a fact before either one starts working."

Output: `work.md`, `execute-wave-pre.md`, and `verify-post.md`, each gaining
one new step that is prose, not new script — the deterministic work already
lives in `cairn-lease.sh` (Plan 15-01), these files only decide when to
call it and what to do with its report.
</objective>
